# Projeto ConsultaCep

Aplicação desktop feita em Delphi que consome a API do ViaCEP e salva os dados em um banco de dados PostgreSQL.

## Funcionalidades

- Consulta de CEP usando a API: https://viacep.com.br/
- Preenchimento automático dos campos com base na resposta da API
- Salvamento ou atualização dos dados no banco de dados
- Exemplo de busca de todos os CEPs do estado do Paraná (PR)

## Tecnologias utilizadas

- Delphi (pode ser a versão Community)
- PostgreSQL
- REST Client do Delphi
- Postman ou Insomnia para testes
